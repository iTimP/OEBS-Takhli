# ระบบยืม-คืนพัสดุสำนักงาน (ใช้ฐานข้อมูล Supabase)

เว็บหน้าเดียว (HTML + JavaScript) ใช้ Supabase เป็นฐานข้อมูลและระบบล็อคอิน ฝากบน GitHub Pages ได้ฟรี

## สิทธิ์การใช้งาน
| ผู้ใช้ | ทำอะไรได้ |
|---|---|
| ทุกคน (ไม่ต้องล็อคอิน) | ดูพัสดุ ดูรายการที่กำลังยืม และยืมพัสดุ |
| เจ้าหน้าที่ (ล็อคอิน) | เพิ่มพัสดุ (ทะเบียนรับ) แก้ไข ลบ รับคืนพัสดุ และดูประวัติการคืน |

สิทธิ์ถูกบังคับที่ฐานข้อมูลด้วย Row Level Security ไม่ใช่แค่ซ่อนปุ่มในหน้าเว็บ

## ขั้นตอนติดตั้ง
1. **สร้างโปรเจกต์** ที่ https://supabase.com (เลือก Region ใกล้ไทย เช่น Singapore)
2. **สร้างตาราง**: เปิด *SQL Editor* คัดลอกไฟล์ `supabase/01_schema.sql` ไปรัน (ถ้าอยากได้ข้อมูลตัวอย่าง รัน `03_seed_demo.sql` ด้วย)
3. **สร้างบัญชีเจ้าหน้าที่**
   - *Authentication > Users > Add user* ใส่อีเมลและรหัสผ่าน (อย่างน้อย 6 ตัวอักษร) แล้วติ๊ก *Auto Confirm User*
   - แก้อีเมล ชื่อ และแผนกใน `supabase/02_add_staff.sql` แล้วรันใน SQL Editor (ทำทีละคน)
4. **ปิดการสมัครสมาชิกเอง**: *Authentication > Sign In / Providers* ปิด *Allow new users to sign up*
5. **ใส่ค่าเชื่อมต่อ**: *Project Settings > API* คัดลอก Project URL และ anon (publishable) key ไปใส่ใน `config.js`
6. **อัปโหลดขึ้น GitHub**: สร้าง repository แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ลาก-วางที่หน้า *Add file > Upload files* ได้)
7. **เปิดเว็บ**: *Settings > Pages > Build and deployment* เลือก *Deploy from a branch*, Branch `main`, โฟลเดอร์ `/ (root)` รอสักครู่จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อ-repo/`

## ความปลอดภัย
- anon key เปิดเผยในหน้าเว็บได้ตามปกติ เพราะข้อมูลถูกป้องกันด้วย RLS
- **ห้ามนำ service_role key มาใส่ในไฟล์ใด ๆ** และห้ามอัปโหลดขึ้น GitHub
- การยืมเปิดให้ทุกคนใช้ ฐานข้อมูลตรวจจำนวนว่างให้อัตโนมัติ (ยืมเกินจำนวนไม่ได้)
- ผู้ที่ไม่ได้ล็อคอินจะไม่เห็นประวัติการคืนและทะเบียนรับ

## โครงสร้างไฟล์
```
index.html            หน้าเว็บระบบ
config.js             ใส่ Project URL และ anon key
logo.jpg              ตราหน่วยงาน
supabase/01_schema.sql   ตาราง ฟังก์ชัน และสิทธิ์
supabase/02_add_staff.sql เพิ่มเจ้าหน้าที่
supabase/03_seed_demo.sql ข้อมูลตัวอย่าง (ไม่บังคับ)
```

## หมายเหตุ
- ล็อคอินด้วย **อีเมล** (Supabase กำหนดรหัสผ่านอย่างน้อย 6 ตัวอักษร จึงใช้บัญชีทดลองแบบ `tim / 1234` เดิมไม่ได้)
- ถ้าต้องการเปลี่ยนรายการประเภทพัสดุ วิธีได้มา หรือแหล่งเงิน แก้ได้ที่ตัวแปร `TYPES`, `METHODS`, `FUNDS` ใน `index.html`
